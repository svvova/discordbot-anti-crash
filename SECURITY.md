# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, report it privately so we can investigate and patch it responsibly.

You can report vulnerabilities by opening a GitHub Security Advisory or by contacting the maintainers directly if contact information is provided in the repository.

We aim to acknowledge reports within 48 hours and provide a fix or mitigation plan within 7 days when possible.

## Disclosure Policy

- Please allow maintainers reasonable time to address the issue before disclosing it publicly.
- Once fixed, we will publish a release note and, when appropriate, credit the reporter.
